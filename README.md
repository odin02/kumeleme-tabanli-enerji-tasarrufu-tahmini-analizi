# kumeleme-tabanli-enerji-tasarrufu-tahmini-analizi
## Proje Hakkında
Bu proje, hanehalkı enerji tüketim verilerini analiz ederek kümeleme tabanlı enerji tasarrufu tahminleri ve önerileri geliştirmeyi amaçlamaktadır.

## Mevcut Durum (Work in Progress)
Şu ana kadar veri setlerinin projeye dahil edilmesi, veri temizleme ve ön işleme (Data Preprocessing) adımları tamamlanmıştır. Bir sonraki aşamada Keşifsel Veri Analizi (EDA) gerçekleştirilecektir.
